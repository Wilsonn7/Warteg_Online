[Warteg Online](https://wilsonn7.github.io/Warteg_Online/)

Warteg Online adalah platform aplikasi yang berbasis web yang menghadirkan pemesanan makanan warteg secara lebih praktis dan efisien. Project ini bertujuan untuk menjembatani kuliner lokal indonesia dengan teknologi digital yang berkembang pesat


**Katalog Menu Interaktif**: Pilih berbagai variasi lauk, sayur, dan makanan khas warteg lengkap dengan harga dan detail porsi.
**Manajemen Keranjang Belanja**: Tambahkan, ubah porsi, atau hapus menu favorit sebelum melakukan checkout.
**Custom Pesanan**: Catatan khusus untuk preferensi pesanan (misal: *bumbu terpisah*, *pedas sedang*, dsb).
**Responsif & User-Friendly**: Desain antarmuka yang ramah pengguna dan nyaman diakses baik via desktop maupun smartphone.

**Frontend**: HTML5, CSS3, JavaScript
